For the full iOS integration guide, see the [Fanmeter iOS README](https://github.com/pluggableai/fanmeter-readme/blob/main/README-ios-v5.md).

Swift Package Manager usage example (Xcode: File > Add Package Dependencies...):

```
https://github.com/pluggableai/fanmeter-sdk-ios-pod
```

Or in `Package.swift`:

```
.package(url: "https://github.com/pluggableai/fanmeter-sdk-ios-pod", from: "5.1.0")
```

**Note:** CocoaPods is no longer supported. CocoaPods trunk stopped accepting new versions, so 5.0.1 is the last version available through CocoaPods. Use Swift Package Manager for 5.1.0 and later.
